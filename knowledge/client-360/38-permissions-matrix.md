# 38. Матрица прав

Обозначения: `R` — чтение, `W` — изменение, `E` — экспорт, `A` — администрирование.

| Домен | Владелец | Гузель | Преподаватель | Бухгалтер | Маркетолог |
|---|---|---|---|---|---|
| Семья и контакты | R/W/E/A | R/W | огранич. R | минимум R | псевдоним. R |
| Дети и обучение | R/W/E/A | R/W по задачам | R/W | нет | агрегаты |
| Согласия | R/W/E/A | R + запись запроса | R | нет | итоговый статус |
| Переписка | R/W/E/A | R/W | по ученику | нет | без личной переписки |
| Оплаты | R/W/E/A | статус R | нет | R/W/E | агрегаты |
| Расходы / прибыль | R/W/E/A | нет | нет | R/W/E | агрегаты кампаний |
| Кампании | R/W/E/A | dry-run R | нет | нет | R/W, без запуска |
| Запуск массовой отправки | A | нет | нет | нет | нет без approval |
| Экспорт всей базы | A | нет | нет | финансовый контур | нет |
| Удаление данных | A + процесс | создать запрос | нет | legal hold input | нет |
| API keys / secrets | A | нет | нет | нет | нет |
| Аудит | R/E/A | собственные действия | собственные | собственные | собственные |

## Принципы

- deny by default;
- минимальные права;
- временный доступ имеет expiry;
- production доступ отдельно от staging;
- увольнение / завершение проекта немедленно отзывает доступ;
- shared accounts запрещены;
- экспорт водяным знаком / audit ID, где возможно;
- чувствительные поля скрыты в списках.

## Break-glass

Экстренный доступ:

- обоснование;
- ограниченное время;
- уведомление владельца;
- полный аудит;
- автоматический отзыв;
- последующий review.
