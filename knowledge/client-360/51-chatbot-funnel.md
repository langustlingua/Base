# 51. Поведенческая воронка чат-ботов LANGUST

Платформы: Telegram и MAX  
Аудитория: родитель младшего школьника  
Основной продуктовый вход: 3 пробных дня  

## 1. Что заменяет старый сценарий

Старый набросок «боль → бонус → оффер через минуту → час на покупку → FOMO» не используется.

Новая логика:

`понять ситуацию → дать микроценность → предложить пробник → довести до действия ребёнка → показать результат → оффер → помощь/возражение → onboarding`.

## 2. Точки входа

| Источник | Start code | Первый контекст |
|---|---|---|
| Reels про забывание слов | `reel_memory_*` | как учить слова |
| Reels про Spotlight | `reel_spotlight_*` | текущая школьная тема |
| сторис | `story_*` | тема конкретной сторис |
| лендинг 2 класса | `site_grade2_*` | сразу 2 класс |
| Смоленск | `smolensk_*` | 2 класс + локальный оффер |
| QR/offline | `qr_*` | источник кампании |
| помощь существующему | signed link | авторизованный support route |

`*` — короткий server-side code без PII.

## 3. Состояния

`new`, `context_known`, `grade_known`, `problem_known`, `micro_value`, `trial_intent`, `lead_created`, `trial_created`, `no_login`, `started`, `first_value`, `engaged`, `offer_shown`, `checkout`, `purchased`, `objection`, `human_handoff`, `paused`, `suppressed`.

## 4. Старт

### BOT-01. Первое сообщение

**Текст**

Здравствуйте! Я бот LANGUST. Помогу подобрать пробный маршрут по школьному английскому и, если понадобится, передам вопрос Татьяне или Гузель.

Вы родитель школьника?

**Кнопки**

- «Да, хочу помочь ребёнку»
- «Уже есть доступ»
- «Нужна помощь человека»

Не начинать с длинного рассказа о продукте и не просить телефон.

### BOT-02. Класс

В каком классе ребёнок сейчас?

Кнопки: `1`, `2`, `3`, `4`, `Другой вариант`.

Если продукт доступен только для второго класса, другим классам не показывать ложный оффер. Сохранить интерес, предложить релевантный доступный материал или честно сообщить статус.

### BOT-03. Что сейчас труднее

Что чаще всего происходит с английским дома?

Кнопки:

- «Не понимает задание»
- «Учит и забывает слова»
- «Не может читать»
- «Не делает без меня»
- «Не нашли тему Spotlight»
- «Другое»

## 5. Микроценность

Бот отвечает одним релевантным объяснением. Не отправляет сразу пять файлов.

### Ветка: не понимает задание

Во втором классе ребёнок часто застревает не на английском слове, а на самой инструкции. Сначала полезно разобрать один тип задания, а уже потом требовать самостоятельность.

В LANGUST можно открыть ту же тему Spotlight и пройти короткую последовательность: объяснение → пример → одно действие ребёнка.

**Кнопка:** «Показать, как выбрать тему»

### Ветка: учит и забывает

Одного повторения списка обычно недостаточно. Слово нужно услышать, произнести, узнать в картинке и встретить ещё раз в задании.

Поэтому первый пробный урок лучше оценивать не по количеству выученных слов, а по тому, смог ли ребёнок узнать их в другом упражнении.

**Кнопка:** «Попробовать на школьной теме»

### Ветка: не может читать

Если ребёнок угадывает слово по картинке, это ещё не чтение. Полезно разделить задачу: услышать звук, увидеть сочетание букв, произнести и только потом читать целиком.

**Кнопка:** «Открыть пробный маршрут»

### Ветка: не делает без мамы

В пробные дни не нужно сразу уходить из комнаты. Помогите выбрать нужную тему, а дальше не объясняйте заранее — посмотрите, на каком шаге ребёнок позовёт вас.

Это даст честный ответ, насколько формат помогает именно вашей семье.

**Кнопка:** «Проверить за 3 дня»

### Ветка: не нашли тему

Можно ориентироваться по модулю и странице Spotlight. Если пришлёте номер модуля или безопасное фото страницы без имени ребёнка и школы, человек поможет найти нужный урок.

**Кнопки:** «Выбрать модуль», «Позвать человека»

## 6. Переход к пробнику

### BOT-04. Предложение

Хотите открыть 3 пробных дня и проверить это на теме, которую ребёнок проходит сейчас?

Платить за пробник не нужно. Сначала вы увидите, понятен ли ребёнку формат.

**Кнопки:** «Открыть 3 дня», «Сначала задать вопрос», «Не сейчас».

### BOT-05. Минимальные данные

Запрашивать только то, чего не хватает:

1. имя родителя для обращения;
2. email, если доступ выдаётся по email;
3. имя ребёнка — необязательно на первом шаге;
4. класс и учебник;
5. согласие на обработку заявки;
6. отдельный выбор будущих сообщений в боте.

Текст перед email:

На этот адрес придут данные для входа. Он нужен для пробного доступа, а не для автоматической подписки на рекламную рассылку.

### BOT-06. Подтверждение заявки

Заявка принята. Сейчас система создаёт доступ. Я напишу здесь, когда он будет готов.

Если понадобится человек, нажмите «Помощь» — перепечатывать всё заново не придётся.

## 7. Доступ создан

### BOT-07. Первый шаг

Пробный доступ открыт.

Начните не с первого урока подряд, а с темы, которую ребёнок проходит в школе сейчас. В первый раз помогите только выбрать урок, затем посмотрите, сколько он сможет сделать сам.

**Кнопки:** «Открыть курс», «Помочь выбрать тему», «Не получается войти».

Ссылка должна быть короткоживущей или вести на безопасную авторизацию; пароль в сообщении по возможности не передаётся.

## 8. Поведенческие ветки пробника

### BOT-08A. Нет входа через 2 часа

Пробный курс пока не открывался. Возможно, письмо потерялось или вход оказался непонятным.

**Кнопки:** «Повторить ссылку», «Не принимает пароль», «Белый экран», «Пока не успели».

Не показывать цену.

### BOT-08B. Вошёл, но не начал

Вход получился. Теперь нужен только один шаг — выбрать модуль Spotlight, который сейчас идёт в школе.

**Кнопки:** «Выбрать модуль», «Пришлю страницу учебника», «Справлюсь сама».

### BOT-08C. Начал, но нет первого результата

Не нужно проходить весь урок. Пусть ребёнок закончит одно короткое упражнение. Если застрял, выберите «Помощь» и укажите название урока.

**Кнопки:** «Продолжить», «Помощь».

### BOT-09. Первое упражнение выполнено

Первый шаг сделан. Сейчас важнее не количество заданий, а то, что ребёнок понял порядок и смог завершить действие.

При следующем подходе снова выберите школьную тему и сначала дайте попробовать самостоятельно.

**Кнопка:** «Продолжить пробник».

### BOT-10. Второй вход или завершённый урок

Теперь уже можно оценивать формат не по обещаниям, а по вашему опыту.

Обратите внимание:

1. Понимает ли ребёнок, что делать дальше.
2. Сколько раз понадобилась ваша помощь.
3. Легче ли после занятия открыть школьный Spotlight.

**Кнопки:** «Следующая тема», «У меня вопрос», «Узнать условия».

## 9. Оффер

### BOT-11S. Смоленск

Показывается только после активации и при действующем подтверждённом оффере.

Для второклассников Смоленска доступ на учебный год стоит 7 900 ₽ по промокоду «Смоленск» — 60% скидка. Предложение действует до 5 октября 2026 года и после этого закрывается.

Покупать имеет смысл, только если пробный формат подошёл вашему ребёнку.

**Кнопки:** «Посмотреть условия», «Задать вопрос», «Пока не подходит».

### BOT-11G. Стандартный оффер

За пробные дни вы уже могли проверить, понятен ли ребёнку формат и нужна ли постоянная помощь взрослого.

Если хотите продолжить, я покажу актуальные условия. Цена берётся из действующего реестра, а не из текста бота.

**Кнопки:** «Посмотреть условия», «Есть вопрос», «Не продолжать».

## 10. Окончание пробника

### BOT-12. За три часа

Пробный доступ закончится сегодня в {trial_end_time_local}.

Если ребёнок успел попробовать и формат подошёл, занятия можно продолжить. Если не успели или возникла ошибка, выберите точную причину — повторно уговаривать бот не будет.

**Кнопки:** «Продолжить», «Не успели», «Была ошибка», «Не подходит».

## 11. После пробника

### BOT-13. Причина

Чтобы не присылать неподходящие сообщения, что помешало решить?

Кнопки:

- «Не успели попробовать»
- «Ребёнку было сложно»
- «Не нашли тему»
- «Вопрос по цене»
- «Пока неактуально»
- «Позвать человека»

`Пока неактуально` прекращает продажную ветку. Остальные ответы создают релевантный next action.

## 12. Checkout

### BOT-14. Оплата начата, но не завершена

Вы открывали оплату, но она не завершилась. Помешала техническая ошибка или вы решили пока не продолжать?

**Кнопки:** «Ошибка оплаты», «Передумали», «Вернуться к оплате».

Одно сообщение. Без серии «карта не прошла — срочно попробуйте ещё».

## 13. После покупки

### BOT-15. Доступ подтверждён

Оплата прошла, доступ продолжен.

Начните с темы Spotlight, которую ребёнок проходит сейчас. Если не уверены, какой урок выбрать, нажмите кнопку — Гузель поможет.

**Кнопки:** «Открыть курс», «Выбрать тему», «Настроить уведомления».

Сообщение отправляется только после сверки payment + access.

## 14. Поддержка

### BOT-16. Handoff

Я передам вопрос человеку. Выберите тему, чтобы он сразу увидел контекст:

- вход;
- доступ;
- урок;
- оплата;
- возврат;
- данные и приватность;
- другое.

После выбора:

Вопрос передан. Ответ придёт здесь в рабочее время {support_hours}. Автоматические предложения пока остановлены.

## 15. Подписка после пользы

После микроценности или пробника, но не в первом сообщении:

Хотите иногда получать здесь короткие подсказки по школьному английскому и информацию об акциях LANGUST?

**Кнопки:** «Да, не чаще раза в неделю», «Только важное по доступу», «Нет».

Выбор фиксируется отдельно от email.

## 16. Частота

- service reply — по факту запроса;
- marketing — только при согласии;
- не более двух автоматических контактов за 24 часа по всем каналам;
- не дублировать email с той же задачей;
- после свободного ответа автоматика ждёт классификации;
- после handoff продажи остановлены;
- после покупки офферы пробника отменены;
- `/stop` действует немедленно.

## 17. Контентный режим

Бот не превращается в ежедневный канал. Полезные серии запускаются отдельно:

- почему слово забывается;
- как выбрать тему Spotlight;
- как понять, где ребёнок застрял;
- как проверить самостоятельность без давления;
- как пройти короткую учебную сессию.

Каждая серия имеет явное согласие, частоту, конец и кнопку выхода.

## 18. Метрики этапов

| Этап | Целевое событие |
|---|---|
| старт | `bot_started` |
| контекст | `bot_problem_selected` |
| микроценность | `bot_micro_value_viewed` |
| намерение | `bot_trial_requested` |
| заявка | `lead_created` |
| доступ | `trial_created` |
| активация | `first_login` |
| первый результат | `first_activity_completed` |
| повтор | `second_session_started` |
| оффер | `offer_viewed` |
| оплата | `payment_succeeded` |
| удержание | `active_day_7` |

Главная диагностика — на каком переходе теряется человек, а не средняя «конверсия бота».

## 19. A/B-тесты после запуска

Только после стабильной базовой версии:

1. вопрос о проблеме до класса или после;
2. текстовая микроценность против короткой карточки;
3. пробник сразу против предварительного выбора темы;
4. оффер после first value против после second session;
5. формулировка кнопки, одна переменная за тест.

Не тестировать искусственный дефицит, скрытое согласие и давление на родительскую вину.

## 20. Приёмка воронки

- все кнопки ведут в определённое состояние;
- у каждого состояния есть fallback и handoff;
- повторный callback безопасен;
- после отказа нет продаж;
- после покупки нет trial-оффера;
- цена всегда из offer registry;
- другой класс не получает нерелевантный курс;
- source attribution сохраняется;
- свободный вопрос не теряется;
- Telegram и MAX создают одинаковые бизнес-события;
- история видна в Client 360;
- бот не хранит пароль и не публикует токен;
- тексты проходят owner approval до production.
