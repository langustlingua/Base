# 37. Ежедневная сводка

## Получатели

- Татьяна — полный управленческий блок;
- Гузель — только рабочая очередь и необходимые детали;
- другим ролям — их собственные задачи.

## Утро

```text
LANGUST · сегодня

Новые заявки: 4
Без первого ответа: 2
Пробники без входа >2ч: 3
Заканчиваются сегодня: 5
Входящие без ответа: 2
Оплата без доступа: 1 ⚠️
Просроченные обещания: 1 ⚠️
Открытые high cases: 0
Разрешённые поздравления: 1

Главный приоритет:
Оплата семьи X подтверждена, доступ не продлён.
```

## Вечер

- заявки получены / обработаны;
- trial activation;
- first value;
- покупки и чистая сумма;
- возвраты;
- support SLA;
- невыполненные задачи;
- повторяющаяся проблема дня;
- отправленные кампании и complaints;
- аномалии данных.

## Правила

- не отправлять полные email/телефоны в сводке;
- ссылка ведёт в защищённую карточку;
- не перечислять детей в общей почтовой рассылке сотрудникам;
- нулевые срочные показатели можно свернуть;
- при critical событии не ждать утренней сводки;
- одна и та же проблема не дублируется десятью строками.

## Еженедельная сводка владельцу

- воронка по когортам;
- доход / расходы / прибыль;
- источники;
- удержание;
- причины отказа;
- нагрузка Гузель;
- качество данных;
- одно предлагаемое решение.
