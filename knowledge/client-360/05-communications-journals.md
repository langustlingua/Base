# 05. Контакты, дневники и журналы

## Журнал контактов

Каждый email, WhatsApp, звонок, форма, комментарий и обращение создают одну запись `interaction`.

Обязательные поля:

- дата и время;
- канал;
- входящий / исходящий;
- участники;
- краткая тема;
- фактическое резюме;
- результат;
- следующий шаг;
- срок;
- ответственный;
- ссылка на оригинал в источнике;
- согласие / основание контакта.

Не копировать бесконтрольно всю переписку в заметку. Резюме должно быть короче исходника и содержать только рабочие факты.

## Дневник семьи

Хронологическая лента:

- заявка;
- выдача пробника;
- первый вход;
- проблемы;
- ответы сотрудника;
- первый результат;
- оффер;
- оплата;
- начало курса;
- изменение активности;
- продление;
- отзыв или уход.

Лента строится из событий автоматически. Ручные записи маркируются именем автора.

## Учебный дневник ребёнка

Показывает:

- текущий учебник и модуль;
- последнюю сессию;
- число коротких занятий за неделю;
- завершённые задания;
- темы, где было несколько попыток;
- новые слова на повторении;
- важные вехи;
- вопрос родителю / учителю;
- следующий рекомендуемый урок.

Не показывать родителю ложную точность вроде «ребёнок знает 83% английского». Использовать конкретные наблюдаемые факты.

## Журнал обещаний

Отдельно фиксировать всё, что сотрудник пообещал:

| Поле | Пример |
|---|---|
| обещание | «Пришлю ссылку на нужный модуль» |
| кому | семья / родитель |
| кто обещал | Татьяна / Гузель |
| срок | сегодня 18:00 |
| статус | open / done / overdue / cancelled |
| подтверждение | ссылка на отправленное сообщение |

Невыполненное обещание важнее очередного маркетингового письма. Пока есть просроченное обещание, продажи этой семье приостанавливаются.

## Журнал поддержки

Для каждой проблемы:

1. Категория.
2. Влияние: не может войти / частично мешает / вопрос.
3. Первый ответ.
4. Диагностика.
5. Корневая причина.
6. Что сделали.
7. Проверка с клиентом.
8. Закрытие.
9. Нужно ли исправление продукта или инструкции.

Повторяющиеся причины становятся задачами продукта. Например: белый экран в Яндекс Браузере — это не серия «невнимательных клиентов», а сигнал сделать понятную инструкцию и проверить кэш/совместимость.

## Журнал возражений

Хранить не произвольные метки, а справочник:

- не успели попробовать;
- не смогли войти;
- не нашли школьную тему;
- ребёнку слишком сложно;
- ребёнку слишком легко;
- нет времени;
- цена;
- предпочитают репетитора;
- уже есть другой курс;
- нет доверия онлайн-формату;
- отложили до следующего года;
- продукт не подходит;
- причина не выяснена.

У каждой причины: дата, источник, свободный комментарий, разрешённый следующий шаг.

## Журнал задач

Виды задач:

- перезвонить;
- помочь войти;
- подобрать урок по фото учебника;
- проверить оплату;
- продлить / остановить доступ;
- ответить на вопрос;
- запросить обратную связь;
- исправить данные;
- обработать отзыв согласия;
- удалить / экспортировать данные;
- связаться перед окончанием доступа.

Задача без срока и ответственного — не задача, а заметка.

## Ежедневный журнал команды

Утренний список:

- новые заявки без первого ответа;
- пробники без входа более 2 часов;
- активные пробники, заканчивающиеся сегодня;
- брошенные оплаты;
- непрочитанные входящие сообщения;
- просроченные обещания;
- платежи с ошибкой;
- клиенты с высоким риском ухода;
- дни рождения с разрешённым поздравлением;
- запросы на удаление / исправление данных.

Вечерний итог:

- сколько заявок обработано;
- сколько активировано;
- сколько вопросов закрыто;
- какие обещания перенесены и почему;
- какие системные проблемы повторились;
- что требует решения Татьяны.
