# 08. Дашборды и показатели

## 1. Сегодня

- новые заявки;
- заявки без ответа;
- пробники без входа;
- пробники, заканчивающиеся сегодня;
- активированные пробники;
- покупки;
- брошенные оплаты;
- проблемы входа;
- просроченные обещания;
- возвраты;
- критические обращения;
- дни рождения, для которых разрешено поздравление.

## 2. Воронка

```text
Посетители
→ начали форму
→ отправили заявку
→ получили доступ
→ вошли
→ начали урок
→ выполнили упражнение
→ вернулись второй раз
→ посмотрели тариф
→ начали оплату
→ оплатили
→ занимались через 7 дней
→ продлили
```

Формулы:

- `form_conversion = form_submitted / unique_landing_sessions`
- `access_delivery = trial_created / trial_requested`
- `trial_activation = first_login / trial_created`
- `first_value = first_activity_completed / trial_created`
- `repeat_use = second_session_started / first_login`
- `trial_to_paid = payment_succeeded / activated_trials`
- `lead_to_paid = payment_succeeded / valid_leads`
- `week_1_retention = active_day_7 / new_customers`

## 3. Email

- доставлено;
- hard/soft bounce;
- жалобы;
- отписки;
- ответы;
- клики;
- целевое действие после письма;
- доход и активации по программе;
- усталость: частота на человека;
- доля базы с подтверждённым согласием.

Open rate — диагностический, не главный KPI.

## 4. Продажи и деньги

- валовая выручка;
- возвраты;
- чистая выручка;
- средний чек;
- LTV;
- MRR/повторная выручка, если применимо;
- успешность продлений;
- просроченные платежи;
- выручка по курсу / классу / региону / источнику / промокоду;
- время от заявки до оплаты;
- CAC, когда расходы по каналам доступны;
- payback period.

## 5. Продукт и обучение

- активные ученики 7/30 дней;
- медиана времени до первого урока;
- уроки и упражнения на активного ученика;
- доля завершённых уроков;
- повторная сессия;
- темы с высоким выходом;
- темы с несколькими неуспешными попытками;
- устройства / браузеры с ошибками;
- доля родителей, открывающих отчёты.

## 6. Поддержка

- новые обращения;
- время первого ответа;
- время решения;
- повторное открытие;
- категории;
- корневые причины;
- CSAT;
- число семей, которым продажи отправились при открытой проблеме — должно быть 0.

## 7. Когорты

Смотреть по неделе первой заявки / оплаты:

- активация;
- покупка;
- активность на 7/30/60 день;
- продление;
- LTV;
- возврат;
- канал привлечения.

Без когорт рост новой рекламы может скрыть ухудшение удержания.

## 8. Качество данных

- дубли семей;
- лиды без источника;
- ученики без класса;
- активные курсы без даты окончания;
- оплаты без enrollment;
- сообщения без consent decision;
- задачи без срока;
- события без версии схемы;
- email hard bounce, который всё ещё получает рассылку;
- неразрешённые PII-файлы в публичных местах.
