# 13. Каталог автоматизаций

## Общий контракт

Каждая автоматизация содержит:

```text
key
purpose
trigger
eligibility
exclusions
delay
channel
template_version
frequency_cap
stop_events
success_event
owner
expires_at
```

## Приоритеты

`privacy > complaint/refund > promise > support > access/payment > learning help > retention > sales > content`

Если одновременно подходят две программы, отправляется более приоритетная; вторая пересчитывается после события.

## A01 — новый лид

- Trigger: `form_submitted`.
- Действие: создать/связать семью, задачу первого ответа, проверить consent.
- SLA: личный ответ в рабочее время.
- Stop: invalid / duplicate / contacted.

## A02 — пробник создан

- Trigger: `trial_created`.
- Действие: сервисное письмо с доступом.
- Success: `first_login`.
- Stop: purchase / opt-out не отменяет необходимый сервис, но меняет канал маркетинга.

## A03 — письмо с доступом не найдено

- Trigger: trial_created + 20 минут.
- Eligibility: разрешён соответствующий канал.
- Действие: короткая проверка доставки.
- Stop: first_login / support case.

## A04 — нет входа 2 часа

- Trigger: нет `first_login`.
- Действие: помощь, прямая ссылка, варианты ошибки.
- Exclusion: открытая проблема уже у сотрудника.

## A05 — первый результат

- Trigger: первое `activity_completed`.
- Действие: зафиксировать успех и предложить текущую тему.
- Frequency: один раз на enrollment.

## A06 — оффер после опыта

- Trigger: день 3 или `lesson_completed` с минимальной задержкой.
- Eligibility: активировал пробник, нет покупки.
- Branch: campaign_smolensk / standard.
- Stop: purchase / refusal / case.

## A07 — брошенная оплата

- Trigger: checkout 24 часа без success.
- Действие: спросить «техническая ошибка или решили отложить?».
- Stop: success / explicit refusal.

## A08 — оплата без доступа

- Trigger: payment_succeeded, нет active enrollment 10 минут.
- Действие: urgent task человеку, не маркетинговое письмо.
- SLA: исправить как можно быстрее.

## A09 — onboarding покупателя

- Trigger: payment_succeeded + access confirmed.
- Действие: начать с текущей школьной темы.
- Stop: support issue.

## A10 — 7 дней без занятия

- Trigger: inactivity 7 дней.
- Действие: полезная подсказка с текущей темой.
- Exclusion: каникулы, пауза, открытая проблема.

## A11 — 14 дней без занятия

- Действие: задача человеку / вопрос о барьере.
- Не отправлять ещё одну общую мотивацию.

## A12 — окончание доступа

- T−7 дней: сервисное напоминание.
- T−1 день: точная дата и последствия.
- T+1: если доступ заблокирован — помощь с продлением.
- Stop: renewal_succeeded.

## A13 — ошибка продления

- Trigger: renewal_failed.
- Действие: сервисное сообщение без публикации платёжных деталей.
- Повтор: только по факту нового статуса.

## A14 — закрытие поддержки

- Trigger: case_resolved.
- Действие: спросить, решено ли, затем CSAT.
- Не просить отзыв о бренде, пока клиент подтверждает техническое исправление.

## A15 — milestone

- Trigger: реальная учебная веха.
- Действие: отчёт родителю с фактами.
- Cap: не чаще одного раза в неделю.

## A16 — рекомендация

- Trigger: повторная активность + положительная обратная связь.
- Действие: мягко попросить поделиться.
- Stop: already_asked / no / complaint.

## A17 — день рождения

- Trigger: разрешение + month/day.
- Действие: непродающее поздравление через родителя.
- Cap: один раз в год.

## A18 — права на данные

- Trigger: privacy request.
- Действие: case high priority, остановить нерелевантные автоматизации.
- Никакого маркетинга до закрытия.

## Защита от циклов

- automation run получает уникальный `run_id`;
- одно событие не может запустить одну программу дважды;
- отправка письма не считается пользовательским engagement для запуска sales ветки;
- ручная отметка «не писать» имеет больший приоритет, чем любой score;
- каждое правило имеет дату выключения и владельца.
