# 27. Матрица сроков хранения

Сроки ниже — проектные категории, не утверждённые юридические сроки. Конкретные значения устанавливаются после проверки применимого права, договоров, налоговых обязанностей и архитектуры хранения.

| Категория | Цель | Старт срока | Действие в конце |
|---|---|---|---|
| Неуспешная заявка | обработка обращения | закрытие / отсутствие активности | удалить или обезличить |
| Контакт клиента | исполнение договора | завершение отношений | минимизировать, затем удалить по политике |
| Маркетинговое согласие | доказательство разрешения | отзыв / окончание отношений | сохранить минимальное доказательство по утверждённому сроку |
| Suppression | не писать повторно | отписка / complaint | хранить минимальный hash/адрес в защищённом контуре |
| Учебная активность | услуга и отчёты | окончание доступа | агрегировать или удалить |
| Детальная web-сессия | аналитика | завершение сессии | короткий срок, затем агрегат |
| Агрегированная аналитика | улучшение продукта | период отчёта | обезличенное хранение |
| Поддержка | решение и качество | закрытие case | ограниченный срок |
| Платёж / чек | бухгалтерские обязанности | операция / отчётный период | по применимому обязательному сроку |
| Отзыв / UGC | публикация | отзыв разрешения / срок лицензии | снять публикацию, обработать копии |
| Аудит безопасности | расследование | событие | срок по security policy |
| Резервная копия | восстановление | создание backup | автоматическое уничтожение по циклу |
| Экспорт сотрудника | рабочая задача | создание | автоматическое удаление через короткий срок |

## Состояния удаления

`active → retention_hold? → scheduled_for_deletion → deleted_from_primary → expired_from_backups → verified`

## Legal hold

Если данные нужны для спора или обязательного хранения:

- фиксируется основание;
- замораживается только необходимая категория;
- маркетинговое использование не продолжается;
- назначается дата пересмотра;
- доступ ограничивается.

## Обезличивание

Это не замена имени на UUID, если связь можно восстановить. Для аналитики:

- удалить прямые идентификаторы;
- убрать редкие комбинации;
- агрегировать дату и географию;
- разорвать таблицу соответствий;
- проверить риск повторной идентификации.

## Удаление семьи

Процесс строит карту всех систем:

- Client 360;
- ProgressMe;
- кабинет;
- Tilda / формы;
- email provider;
- WhatsApp / support;
- файлы и uploads;
- аналитика;
- резервные копии;
- подрядчики.

Результат — протокол: что удалено, что обезличено, что обязаны сохранить и на каком основании.
